# Online Food Delivery System - Backend

## Project Overview

This is the backend of a full-stack Online Food Delivery System built using Spring Boot and MySQL. It provides REST APIs for user authentication, restaurant management, menu management, cart operations, order processing, and admin dashboard functionalities.

## Features

* JWT Authentication and Authorization
* Role-Based Access Control (ADMIN, CUSTOMER)
* User Registration and Login
* Restaurant Management
* Menu Item Management
* Cart Management
* Order Placement and Tracking
* Order Status Updates
* Admin Dashboard APIs
* Global Exception Handling
* Spring Security Integration

## Tech Stack

* Java 21
* Spring Boot
* Spring Security
* JWT

* Maven

* Authentication APIs

Database Name:

food_delivery

## Run Locally

1. Clone repository
2. Configure MySQL database
3. Update application.properties
4. Run:

mvn spring-boot:run

Backend runs on:

http://localhost:8080
